## What this repository contains

This repo is organized into project-focused folders, each showing a different stage of the data lifecycle.

### 1. Data Pipeline

Folder: `Data_pipeline`

This project focuses on building a complete data pipeline around e-commerce data. It demonstrates how raw transactional data can be extracted, transformed, and prepared for analytics.

Included artifacts:

- `python_sql_script.ipynb` — Python + SQL workflow for ingestion, transformation, and analysis
- `ecommerce_research_queries.sql` — analytical SQL queries used to explore trends and patterns
- `ecomerce_data/` — source datasets used in the pipeline
- `ecommerce_visual_graph.png` and `ecommerce_visual_graph2.png` — visual analytics outputs
- `ecom_ERD.png` — entity relationship diagram showing data structure
- `Ecommerce_visuals.pbix` — Power BI dashboard file for business-facing reporting
- `readme.md` — deeper project documentation for the pipeline work

This section reflects the full journey from raw data to business-ready insights.

### 2. Data Warehouse

Folder: `Data_warehouse`

This project focuses on warehouse design and schema engineering. It uses the classic DVD rental sample database and demonstrates how a normalized 3NF structure can be transformed into a warehouse-oriented model optimized for analytics.

Included artifacts:

- `createtable.sql` — table creation scripts
- `dvdrental_inserting.sql` — data insertion logic
- `dvdrentalERD.drawio.png` — ERD of the source database
- `readme.md` — warehouse project documentation

This work highlights:

- dimensional modeling
- fact and dimension table identification
- schema optimization
- analytical querying and warehouse architecture design
